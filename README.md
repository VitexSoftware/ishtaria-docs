# ishtaria-docs

Documentation of Ishtaria, written in reStructuredText and built with Sphinx.

Published at https://vitexsoftware.github.io/ishtaria-docs/ and as the Debian package `ishtaria-doc`.

```sh
sudo apt install python3-sphinx python3-sphinx-rtd-theme graphviz
make html          # warnings are errors
```

Contents: vision, roadmap, architecture (server, client, simulation, persistence), federation (agreements, travel tickets, economy), operator guide, development guide and decision records.

## Part of Ishtaria

Ishtaria is an open-source, persistent, federated virtual planet of Earth size.
