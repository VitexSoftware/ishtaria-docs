Contributing
============

* Discuss larger changes in an issue first; architectural ones as a
  decision record (:doc:`../decisions/index`).
* Rust: ``cargo fmt``, ``cargo clippy -- -D warnings``, ``cargo test``.
* Protocol changes need an updated schema, an example and a passing
  ``tests/validate_examples.py``.
* Documentation is English. Czech translation is welcome through
  ``sphinx-intl`` (``locale/cs``).
* By contributing you agree to license your work under the repository's
  licence.
