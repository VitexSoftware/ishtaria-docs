Repositories
============

All repositories live in the `VitexSoftware <https://github.com/VitexSoftware>`_
GitHub organisation.

.. list-table::
   :header-rows: 1
   :widths: 22 14 64

   * - Repository
     - Licence
     - Purpose
   * - `ishtaria-core <https://github.com/VitexSoftware/ishtaria-core>`_
     - MIT
     - Shared Rust library: identities, items, rulesets, later physics and
       crafting rules. Linked into server, worldgen and client.
   * - `ishtaria-server <https://github.com/VitexSoftware/ishtaria-server>`_
     - AGPL-3.0
     - Authoritative world server and federation endpoint.
   * - `ishtaria-client <https://github.com/VitexSoftware/ishtaria-client>`_
     - MIT
     - Godot 4 client.
   * - `ishtaria-worldgen <https://github.com/VitexSoftware/ishtaria-worldgen>`_
     - MIT
     - Deterministic cube-sphere terrain generator.
   * - `ishtaria-protocol <https://github.com/VitexSoftware/ishtaria-protocol>`_
     - MIT
     - Federation protocol: JSON Schema, CDDL, examples.
   * - `ishtaria-content <https://github.com/VitexSoftware/ishtaria-content>`_
     - CC BY-SA 4.0
     - Base content pack ``core-rules``.
   * - `ishtaria-docs <https://github.com/VitexSoftware/ishtaria-docs>`_
     - CC BY-SA 4.0
     - This documentation (Sphinx, reStructuredText).

Why these licences: see :doc:`../decisions/0004-licensing`.
