0001 – Separate planets linked by portals
=========================================

:Status: Accepted
:Date: 2026-10-04

Context
-------

Worlds are run by independent operators who may link their worlds. Options
were (A) separate planets linked by portals, (B) one shared planet with
regions owned by servers, (C) jointly simulated territory.

Decision
--------

Option **A**. Every world has its own planet; crossings happen through
portals as discrete, signed handovers.

Consequences
------------

* No real-time state synchronisation between servers, no border authority
  problem, outages stay local.
* Travel between worlds becomes gameplay (portals are built by players).
* Seamless shared geography is not possible; revisit only if a strong
  need appears.
